# Kometa-Config-and-Collections

## Description
These are the custom collections I use withing Kometa.

### Custom Collection
Custom collections that aren't picked up by the Kometa franchise default collection.

### Fel-Mel Collection
Creates collections based on Dolby Vision profile 7 full enhancement layer or minimum enhancement layer.

### Reference Audio Video Collection
Creates collections based on Shane Lee's reviews of movies. Also creates Ultimate Bass Collection.
